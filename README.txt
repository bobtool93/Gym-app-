- Peso corporeo e grafico.

- Backup/import completo.
- PWA offline/installabile.

AGGIORNAMENTO GITHUB:
1. Nella repository sostituisci index.html, manifest.webmanifest, sw.js e icon.svg con quelli di questa cartella.
2. Attendi GitHub Pages.
3. Chiudi e riapri l'app installata. Se il telefono mostra la vecchia versione, apri la pagina GitHub Pages una volta e ricarica; il Service Worker aggiornerà la cache.

I DATI RESTANO:
L'aggiornamento del codice non cancella IndexedDB. Prima di aggiornare è comunque consigliato fare un "Esporta tutto" dalla sezione Storico.
