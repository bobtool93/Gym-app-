SKILL TRAINING V3

Funzioni:
- IndexedDB: dati persistenti separati dal semplice file HTML.
- Storico completo per esercizio.
- Registrazione per serie: reps/secondi, carico o progressione, RIR.
- Suggerimento di progressione automatico in base al range e al RIR.
- Dashboard con giorni/esercizi registrati.
- Tracking peso corporeo e grafico.
- Backup completo JSON Import/Export.
- Timer recupero con vibrazione quando supportata.
- PWA/offline: pronta per essere installata come app.

INSTALLAZIONE SU ANDROID
1. Pubblica questi file su un hosting HTTPS (GitHub Pages, Netlify, Vercel ecc.).
2. Apri l'indirizzo con Chrome.
3. Seleziona "Installa app" oppure "Aggiungi a schermata Home".
4. Avrai un'icona indipendente e l'app si aprirà a schermo intero.

NOTA
Il Service Worker/PWA richiede HTTPS (oppure localhost). Aprire index.html direttamente dal file manager non abilita tutte le funzioni PWA.
